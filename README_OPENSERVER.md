# Установка Фабрики новостей на OpenServer

## Шаг 1 — Распаковать папку сайта

Распакуйте архив и скопируйте папку `fabrika_openserver` в:

```
C:\OpenServer\domains\fabrika\
```

Итоговая структура должна выглядеть так:

```
C:\OpenServer\domains\fabrika\
├── index.php
├── .htaccess
├── css\
│   └── app.css
├── js\
│   └── app.js
├── config\
│   ├── database.php   ← настройки БД
│   └── app.php
├── src\
├── views\
└── sql\
    └── schema.sql     ← схема базы данных
```

---

## Шаг 2 — Создать базу данных

1. Запустите OpenServer
2. Откройте **phpMyAdmin** (правой кнопкой на иконке → "phpMyAdmin")
3. Войдите: логин `root`, пароль пустой
4. Нажмите **"SQL"** (вкладка вверху)
5. Вставьте и выполните весь текст из файла `sql\schema.sql`

Или через меню:
- Слева нажмите **"Создать базу данных"**
- Имя: `fabrika`, сравнение: `utf8mb4_unicode_ci`
- Затем выберите базу `fabrika` → вкладка **SQL** → вставьте содержимое `schema.sql`

---

## Шаг 3 — Настройка OpenServer

В трее OpenServer → **"Настройки"** → вкладка **"Домены"**:

- Убедитесь что режим управления доменами = **"Ручное управление"** или **"Автоматический"**
- Корневая папка доменов: `C:\OpenServer\domains\`

Перезапустите OpenServer (красный → жёлтый → зелёный флаг).

---

## Шаг 4 — Проверить config/database.php

Откройте файл `config\database.php` и убедитесь:

```php
return [
    'host'     => 'localhost',
    'port'     => 3306,
    'dbname'   => 'fabrika',   // имя базы которую создали
    'user'     => 'root',      // стандартный логин OpenServer
    'password' => '',          // пароль обычно пустой
    'charset'  => 'utf8mb4',
];
```

Если вы задавали пароль для root в MySQL — впишите его.

---

## Шаг 5 — Открыть в браузере

```
http://fabrika/
```

или если домен не подхватился:

```
http://localhost/fabrika/
```

## Если что-то не работает

**Белая страница / ошибка 500:**
- Откройте `config\app.php` и поставьте `'debug' => true`
- Перезагрузите страницу — увидите текст ошибки

**Ошибка "Cannot connect to database":**
- Проверьте что MySQL запущен (флаг OpenServer зелёный)
- Проверьте `config\database.php` — правильное имя БД и пароль

**Страница не найдена (404 на все страницы):**
- В OpenServer: Настройки → Apache → убедитесь что `mod_rewrite` включён
- Проверьте что файл `.htaccess` скопировался (в Windows скрытые файлы могут не отображаться — включите "Показывать скрытые файлы" в Проводнике)

**Ошибка "Access denied for user root":**
- В phpMyAdmin проверьте пользователя `root` и его пароль
- Впишите правильный пароль в `config\database.php`
